V26.3 — ИСПРАВЛЕНИЕ РЕГИСТРАЦИИ

Причина сообщения про приглашение: в интернете продолжает работать старая версия сайта или в Supabase остался старый триггер регистрации.

Порядок:
1. В проекте Supabase ROO выполните PATCH_V26_3_REMOVE_INVITE_GATE.sql.
2. Запустите INSTALL_AND_PUBLISH_V26_3.bat.
3. Введите Project URL и Publishable key проекта ROO.
4. Дождитесь SUCCESS.
5. Через 1–3 минуты откройте сайт с ?v=26.3 и нажмите Ctrl+F5.
6. На форме входа должна быть видна метка V26.3.

В V26.3 приглашения не нужны. Новый пользователь получает роль «Ожидает назначения».
