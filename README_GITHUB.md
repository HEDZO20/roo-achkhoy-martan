# РОО Ачхой-Мартановского района — ONLINE V24

Рабочая онлайн-система на GitHub Pages + Supabase.

## Обновление

1. Запустить `1_UPDATE_SITE_V24.bat`.
2. Выполнить `supabase/PATCH_V24_DATA_QUALITY.sql` в Supabase SQL Editor.
3. Обновить сайт через `Ctrl + F5`.
