# РОО Ачхой-Мартановского района — ONLINE V22

Рабочая информационная система на GitHub Pages + Supabase.

## Обновление существующего сайта

1. Запустить `1_UPDATE_SITE_V22.bat`.
2. Выполнить один раз `supabase/PATCH_V22_FULL_AUDIT.sql`.
3. Обновить сайт сочетанием `Ctrl + F5`.

## Основное исправление V22

Рейтинг школы или отдела больше не равен 100% без исходных данных.
До появления фактических поручений и результатов отображается `—` или
`Не рассчитан`.

Полный отчёт: `AUDIT_REPORT_V22_RU.txt`.
