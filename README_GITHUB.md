# Информационная система РОО — ONLINE V13

Рабочая онлайн-система Отдела образования Ачхой-Мартановского района.

## Архитектура

- **GitHub (private repository):** исходный код и история обновлений.
- **Vercel:** публичная HTTPS-ссылка на сайт и автоматическая публикация после каждого push в `main`.
- **Supabase:** пользователи, роли, школы, поручения, документы, экзамены, аудит и настройки дизайна.

## Первичная установка

1. Выполнить `supabase/SETUP_CLEAN_SUPABASE.sql` в SQL Editor проекта Supabase.
2. Создать закрытый репозиторий GitHub.
3. Запустить `2_UPLOAD_TO_GITHUB.bat` и вставить HTTPS-адрес репозитория.
4. Импортировать репозиторий в Vercel с Framework Preset **Other**.
5. После публикации указать HTTPS-адрес Vercel в Supabase → Authentication → URL Configuration.

## Обновления

После изменения файлов запустить `UPDATE_GITHUB.bat`. Скрипт создаст commit и отправит его в `main`; Vercel автоматически опубликует новую версию.

## Безопасность

В браузере используется только Supabase **publishable key**. Никогда не добавляйте в репозиторий пароль базы, `service_role` или ключ `sb_secret_...`.

`.vercelignore` исключает SQL, BAT/PowerShell, инструкции и другие служебные материалы из публичной публикации, хотя они сохраняются в закрытом GitHub-репозитории.
