ONLINE V22 — ПОЛНЫЙ АУДИТ ДОСТОВЕРНОСТИ И ИНТЕРФЕЙСА

Главное исправление
-------------------
Рейтинг школы или отдела больше не начинается со 100%.
Если для расчёта ещё нет фактических данных, сайт показывает:
—
Не рассчитан
Недостаточно данных

Порядок обновления
------------------
1. Запустите 1_UPDATE_SITE_V22.bat.
2. Дождитесь SUCCESS.
3. Запустите 2_OPEN_SQL_PATCH_V22.bat.
4. Скопируйте весь PATCH_V22_FULL_AUDIT.sql в открывшийся SQL Editor Supabase.
5. Нажмите Run один раз.
6. Откройте сайт и нажмите Ctrl+F5.

Что исправлено
--------------
- ложные 100% у новых школ и отделов;
- расчёт рейтинга только по фактическим данным;
- отсутствие места в рейтинге до появления показателей;
- вымышленные графики, отчёты, события, обращения и активность;
- пустые состояния всех основных страниц;
- мобильная вёрстка и ширина основного содержимого;
- читаемость мелких подписей, таблиц, карточек и кнопок;
- остатки демонстрационных надписей;
- сохранение цвета, фона и других свойств выбранного блока;
- публикация v22.js и v22.css через GitHub Pages;
- безопасная резервная ветка перед обновлением.

Важно
------
Поручения, ответы школ, файлы, результаты экзаменов, пользователи,
журнал действий и дизайн связаны с Supabase.

Совещания, обращения, проверки, личные задачи, документы и правила
автоматизации пока используют локальное хранение браузера. В V22 они
не показывают вымышленные показатели, но для одновременной работы всех
сотрудников эти модули нужно следующим этапом перенести в Supabase.
