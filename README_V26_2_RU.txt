V26.2 WINDOWS FIX

Причина ошибки ParserError: Windows PowerShell 5.1 неверно прочитал старый PS1 без UTF-8 BOM.

Порядок:
1. Запустите 0_CONFIGURE_SUPABASE_V26_2.bat
2. Введите Project URL проекта ROO
3. Введите Publishable key проекта ROO
4. После SUCCESS запустите 1_UPDATE_GITHUB_V26_2.bat
5. Откройте https://hedzo20.github.io/roo-achkhoy-martan/?v=26.2 и нажмите Ctrl+F5

Не вводите service_role, secret key или пароль базы.
