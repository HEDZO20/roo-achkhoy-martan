ПУБЛИКАЦИЯ ONLINE V13 НА VERCEL
==============================

Вариант без командной строки:
1. Создайте закрытый репозиторий GitHub.
2. Загрузите в него все файлы из этой папки, включая assets и supabase.
3. Откройте Vercel → Add New → Project.
4. Выберите репозиторий.
5. Framework Preset: Other.
6. Build Command оставьте пустым.
7. Output Directory оставьте пустым.
8. Нажмите Deploy.

После публикации скопируйте адрес вида:
https://название-проекта.vercel.app

Откройте Supabase → Authentication → URL Configuration:
• Site URL замените на адрес Vercel;
• в Redirect URLs добавьте:
  https://название-проекта.vercel.app/**
• localhost можно оставить для тестирования.

После этого все сотрудники и школы смогут пользоваться одной ссылкой.
Каждое следующее обновление GitHub автоматически попадёт на Vercel.
