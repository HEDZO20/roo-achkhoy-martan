V26 SMART ANALYSIS — умный анализ ГИА/ЕГЭ/ОГЭ и адаптивный логотип
===================================================================

ГЛАВНОЕ
1. Логотип PNG/JPG/SVG/WebP не обрезается: используется object-fit: contain.
2. Прозрачный PNG остаётся прозрачным.
3. У непрозрачного PNG сайт анализирует пиксели по краям и автоматически подбирает такой же фон контейнера.
4. DOCX/XLSX/XLS/CSV анализируются целиком: таблицы, предметы, школы, динамика, аттестаты, высокие баллы, ОГЭ и расхождения.
5. На сайте появляются вкладки: Обзор, Предметы, Школы, Динамика, Высокие баллы, Проверка данных, Исходные таблицы.
6. Формируются автоматические выводы и оформленные отчёты DOCX с диаграммой, HTML/PDF и Excel.

ВАЖНО ПРО SUPABASE
- Используйте отдельный проект для сайта РОО.
- Не запускайте SQL в LAMAN / vai-market-dev.
- Не присылайте и не вводите service_role, secret key или пароль базы в файлы сайта.
- Для config.js нужны только Project URL и Publishable key.

УСТАНОВКА В НОВЫЙ ПУСТОЙ ПРОЕКТ SUPABASE
1. Создайте отдельный проект Supabase для РОО.
2. Запустите 3_OPEN_FULL_SQL_V26.bat.
3. Скопируйте весь supabase/SETUP_V26_FULL.sql в SQL Editor и нажмите Run.
4. Запустите 0_CONFIGURE_SUPABASE_V26.bat и введите Project URL и Publishable key.
5. Запустите 1_UPDATE_GITHUB_V26.bat.
6. После обновления GitHub Pages зарегистрируйте свой аккаунт на сайте.
7. В SQL Editor назначьте первый аккаунт начальником РОО:
   update public.profiles
   set role='roo_head', status='active'
   where email='ВАША_ПОЧТА';
8. Выйдите с сайта и войдите снова.

ОБНОВЛЕНИЕ С V25
1. Запустите 2_OPEN_SQL_PATCH_V26.bat.
2. Выполните supabase/PATCH_V26_SMART_ANALYSIS.sql.
3. Запустите 0_CONFIGURE_SUPABASE_V26.bat.
4. Запустите 1_UPDATE_GITHUB_V26.bat.

КАК ЗАГРУЗИТЬ АНАЛИТИЧЕСКУЮ СПРАВКУ
Анализ экзаменов -> Загрузить и проанализировать -> выберите DOCX/XLSX/XLS/CSV.
Система не требует Ф.И.О. в каждой таблице и не отклоняет весь документ из-за одной проблемной строки.
Перед сохранением показывается полный предварительный анализ.

КАК ЗАМЕНИТЬ ЛОГОТИП
Настройки -> Фирменное оформление -> выберите изображение.
Фон определяется автоматически. Его можно изменить вручную, как и внутренний отступ.

БЕЗОПАСНОСТЬ
- Исходные аналитические документы хранятся в отдельном закрытом bucket roo-exam-analysis.
- Полный районный анализ доступен только начальнику/заместителю РОО и сотрудникам отделов.
- Школьные роли не получают районные пофамильные списки.
- Логотип хранится отдельно в публичном bucket roo-public.

Для официальной эксплуатации с реальными персональными данными требуется российская инфраструктура и отдельная проверка требований 152-ФЗ.
