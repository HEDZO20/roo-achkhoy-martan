-----------
Эта версия подключена к НОВОМУ проекту Supabase:

В config.js находится только разрешённый publishable key. Секретные ключи
service_role и sb_secret_ в проект не добавлялись.

ПЕРВАЯ УСТАНОВКА НОВОЙ БАЗЫ
----------------------------
1. Запустите OPEN_SUPABASE_SETUP.bat.
2. Откроются файл supabase/SETUP_CLEAN_SUPABASE.sql и SQL Editor нового проекта.
3. Скопируйте SQL полностью, вставьте его в SQL Editor и нажмите Run.
4. Дождитесь сообщения Success без красных ошибок.
5. В Supabase откройте Authentication -> URL Configuration.
6. Для локального запуска укажите:
   Site URL: http://localhost:8080
   Redirect URL: http://localhost:8080/**
7. Запустите START.bat.
8. Зарегистрируйте СВОЙ аккаунт первым. Первый пользователь пустой базы
   автоматически получает роль «Начальник РОО».
9. Только после этого создавайте приглашения отделам и школам.

ВАЖНО
-----
Новая база полностью пустая. Старые пользователи и данные из предыдущего
Supabase сюда не переносятся. Пять отделов и их рабочие почты создаются SQL-скриптом.

АВТОМАТИЧЕСКИЙ ИМПОРТ ЭКЗАМЕНОВ
--------------------------------
Раздел «Анализ экзаменов» принимает XLSX, XLS и CSV. Сайт автоматически:
• находит строку заголовков;
• распознаёт распространённые названия колонок;
• проверяет ФИО, школу, предмет, балл, оценку, статус и опоздание;
• показывает предпросмотр и ошибки;
• может создать отсутствующие школы (начальник РОО/заместитель);
• сохраняет строки в Supabase;
• пересчитывает таблицы, графики, рейтинги и аналитическую справку.

Для максимальной точности используйте колонки:
ФИО, Школа, Класс, Экзамен, Предмет, Балл, Оценка, Статус, Учебный год.

РЕДАКТОР ДИЗАЙНА
----------------
Изменения выбранного блока сохраняются локально и в таблице design_settings.
Редактировать общий дизайн могут Начальник РОО и Заместитель.
После установки чистого SQL дополнительный PATCH V11 выполнять не нужно —
необходимые таблицы и политики уже входят в SETUP_CLEAN_SUPABASE.sql.
