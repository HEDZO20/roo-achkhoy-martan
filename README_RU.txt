ОТДЕЛ ОБРАЗОВАНИЯ АЧХОЙ-МАРТАНОВСКОГО РАЙОНА
V28.3 FINAL AUDIT

НАЗНАЧЕНИЕ
V28.3 — итоговая модульная версия сайта РОО после полного аудита интерфейса, ролей, форм, таблиц, документов и анализа экзаменов.

ОСНОВНЫЕ ИСПРАВЛЕНИЯ
- Анализ экзаменов открывается полноценной страницей сайта, а не тесным окном с отдельной вертикальной прокруткой.
- 8 вкладок анализа переключаются без закрытия страницы и без потери результата.
- Исходные таблицы используют общую прокрутку страницы; горизонтальная прокрутка остаётся только внутри действительно широких таблиц.
- Исправлены отступы, переносы длинного текста, края карточек, панели, кнопки, мобильное меню и заголовок пользователя.
- Пустые показатели отображаются как «—», а не как вымышленные проценты.
- Восстановлены поручения, ответы, согласование, школы, рейтинг, отделы, документы, календарь, обращения, совещания, проверки, роли, уведомления и журнал.
- Усилены проверки обязательных полей и права доступа.
- Добавлена настоящая выгрузка DOCX и оформленная выгрузка Excel.

ОБНОВЛЕНИЕ С V27
1. Запустить 1_OPEN_SQL_V28_3.bat.
2. Выполнить PATCH_V28_FINAL_AUDIT.sql в отдельном Supabase-проекте ROO.
3. Убедиться, что результат содержит V28_3_FINAL_OK.
4. Запустить 2_INSTALL_AND_PUBLISH_V28_3.bat.
5. Ввести Project URL и Publishable key проекта ROO.
6. Дождаться зелёной галочки GitHub Pages.
7. Открыть https://hedzo20.github.io/roo-achkhoy-martan/?v=2830 и нажать Ctrl+F5.

НОВЫЙ ПРОЕКТ БЕЗ V27
Использовать 0_OPEN_FULL_SETUP_V28_3.bat и выполнить SETUP_V28_3_FULL.sql.

БЕЗОПАСНОСТЬ
- Не присылайте и не помещайте в config.js secret key или service_role.
- В браузере используется только Publishable key.
- SQL выполнять только в проекте ROO, не в LAMAN.
- Для настоящих персональных данных требуется российская инфраструктура и организационные меры по защите данных.
