V25 CLEAN PRODUCTION — чистая архитектура без файлов V1–V24.

Сделано:
- регистрация без самостоятельного выбора роли;
- назначение ролей начальником РОО;
- паспорт школы;
- единый импорт CSV/XLS/XLSX/DOCX;
- три типа данных: пофамильные, сводные, аналитическая справка;
- проблемная строка не блокирует весь импорт;
- история импортов;
- отчёты Excel и Word-совместимый DOC с таблицами;
- простое меню по ролям;
- пустые показатели показываются как «—».

Установка базы:
1. Supabase -> SQL Editor -> New query.
2. Выполнить supabase/SETUP_V25_CLEAN.sql.
3. Первый аккаунт НЕ становится начальником автоматически.
4. Для первого начальника РОО после регистрации выполнить в SQL Editor:
   update public.profiles set role='roo_head', status='active' where email='ВАША_ПОЧТА';

Важно:
- XLSX и DOCX читаются локально в браузере после загрузки библиотек с CDN.
- Для российской официальной эксплуатации с персональными данными потребуется российская серверная инфраструктура.
