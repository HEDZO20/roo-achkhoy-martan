V26.3.2 — исправление ошибки Git staging

Причина ошибки V26.3.1:
путь --work-tree заканчивался обратным слешем перед кавычкой. Git for Windows получал повреждённый аргумент и показывал общую справку вместо выполнения git add.

Что исправлено:
- удалён проблемный параметр --work-tree="...\";
- GIT_DIR и GIT_WORK_TREE задаются через переменные среды;
- исходный путь очищается от завершающего обратного слеша;
- добавлен журнал INSTALL_V26_3_2.log;
- публикация выполняется в ветку main;
- SQL повторно запускать не требуется.

Порядок:
1. Распаковать ZIP в новую папку.
2. Запустить INSTALL_AND_PUBLISH_V26_3_2.bat.
3. Ввести Project URL и Publishable key проекта ROO.
4. Дождаться SUCCESS: V26.3.2 was pushed to GitHub.
5. Дождаться зелёной галочки GitHub Pages.
6. Открыть https://hedzo20.github.io/roo-achkhoy-martan/?v=2632 и нажать Ctrl+F5.

На форме входа должна быть метка V26.3.2.
